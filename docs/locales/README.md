# 🌍 Locales & Translations

This folder holds translation files for all supported languages.

- Example: `en.json`, `fr.json`, `es.json`
- Add a new file for each language, using UTF-8 encoding.

## Adding Translations

1. Copy `en.json` as a template.
2. Translate each string value.
3. Submit a PR referencing the new locale.
