# 🦮 Accessibility Guide

WOOFY McWOOFSON is committed to accessibility so everyone can interact with the platform.

## Standards

- Follows WCAG 2.1 AA guidelines.
- All interactive components are keyboard-navigable.
- Uses ARIA labels for all actionable UI elements.

## Testing

- Run accessibility tests with tools like axe-core and Lighthouse.
- Regularly audit UI for color contrast, focus indicators, and screen reader compatibility.

## Reporting Issues

If you find any accessibility barriers, email: accessibility@bakery-street-projct.com.
