# 🌏 Internationalization (i18n) Guide

WOOFY McWOOFSON supports global users with internationalization best practices.

## Guidelines

- All UI strings are externalized for translation.
- Date/time and number formats adapt to locale settings.
- RTL (right-to-left) language support is planned.

## Adding Languages

- Add new locale files in `/locales/`.
- Update language selector in the UI.
- Use Unicode and UTF-8 everywhere.
