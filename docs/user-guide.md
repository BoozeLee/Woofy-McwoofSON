# 🐶 WOOFY User Guide

Welcome to WOOFY McWOOFSON! Here’s how to get started and fetch value from your enterprise AI assistant.

---

## 🏁 Getting Started

1. **Log in:** Use your SSO or AWS credentials.
2. **Access the dashboard:** Go to `/app` in your browser.
3. **Interacting with WOOFY:**
   - Use the chat interface for questions, document fetches, and compliance queries.
   - Try commands like:
     - “Fetch the latest compliance policy”
     - “Show audit logs”
     - “Sit! Run security scan”
4. **Log out** when done for security.

- **How do I reset my password?**
