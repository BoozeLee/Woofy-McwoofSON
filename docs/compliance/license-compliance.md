# 📚 License Compliance

WOOFY McWOOFSON ensures all dependencies are used in accordance with their licenses.

- All dependencies are listed in `package.json` and scanned by [FOSSA](https://fossa.com/) or [Licensee](https://github.com/licensee/licensee).
- Only permissive or compatible licenses (MIT, Apache 2.0, etc.) are allowed.
- Report any non-compliant or unclear licenses to legal@bakery-street-projct.com.

## Audit Process

- Run `make license-check` or equivalent.
- Review new dependencies during PR review.
