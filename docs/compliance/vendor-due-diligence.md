# 🏛️ Vendor Due Diligence Checklist

This checklist is used to assess new vendors before integration.

- [ ] Vendor provides SOC2 or ISO 27001 certification
- [ ] Data encryption at rest and in transit
- [ ] GDPR compliance documented
- [ ] Security incident response plan shared
- [ ] Regular penetration testing conducted
- [ ] Data retention and deletion policies reviewed
- [ ] Subprocessor list provided
