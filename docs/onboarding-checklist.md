# 🐾 Onboarding Checklist

## For New Contributors

- [ ] Accept invitation to GitHub repository.
- [ ] Read and sign the Contributor License Agreement (CLA).
- [ ] Read `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.
- [ ] Clone the repo and run `scripts/setup-env.sh`.
- [ ] Set up your `.env` file (see `.env.example`).
- [ ] Run `make lint` and `make test` to verify your environment.
- [ ] Request access to AWS development resources (if needed).
- [ ] Join team Slack/Teams channels and introduce yourself.

## For New Admins

- [ ] Complete all above contributor steps.
- [ ] Request access to AWS IAM, Secrets Manager, and CloudWatch.
- [ ] Review `docs/admin-guide.md` and `docs/architecture/aws-architecture.md`.
- [ ] Set up 2FA on all accounts.
- [ ] Review incident response and data retention docs.
- [ ] Test your admin access by deploying to a test environment.
