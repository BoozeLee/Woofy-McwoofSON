# Copilot Space – Project Transition & Audit Workspace

This workspace is designed for rigorous, zero-loss project transitions and agent handoffs for the `Bakery-street-projct` suite.  
It contains all instructions, templates, and source files required to ensure continuity, transparency, and maintainability.

---

## Key Files

- `general-instructions.md`: The canonical audit and transition instructions for this Space.
- `DETAILED_TRANSITION_REPORT.md`: The structured transition report draft and template.
- `knowledge-vault/`: Centralized documentation and knowledge artifacts.
- `scripts/update_context.sh`: Script to refresh Copilot Space with latest context.
- `.copilot-space.yml`: Manifest for Copilot Space configuration and context pinning.
- `GITHUB_COPILOT_TOKEN_GUIDE.md`: Guide for securely setting up a GitHub Copilot token.
- `architecture/adr/`: Architecture Decision Records (see below).
---

**How to Use This Workspace**

1. **Follow the instructions in `general-instructions.md` for every audit or transition.**
2. **Update the `DETAILED_TRANSITION_REPORT.md` with each new transition.**
3. **Expand the `knowledge-vault/` directory with new docs, scripts, and references.**
4. **Use `scripts/update_context.sh` to refresh Copilot’s context as the repo evolves.**
5. **Escalate any blockers or ambiguities in the transition process immediately.**
