# Perplexity Integration Security & Credential Handling

- Always store your PERPLEXITY_API_KEY in `.env` (never in code or docs).
- Rotate API keys regularly and document in `CREDENTIAL_ROTATION_AND_HISTORY_CLEANUP.md`.
- No API keys in chat, gig descriptions, or screenshots.
- Amazon Q and Copilot review all Perplexity integration workflows for security compliance.
- If any exposure occurs, IMMEDIATELY rotate and document.
