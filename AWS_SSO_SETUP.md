# 🔐 AWS SSO/Identity Center Setup

## What that link does:
- **AWS Identity Center**: Single sign-on portal
- **Account Access**: Multiple AWS accounts/roles
- **Amazon Q Pro**: May include Q Pro access

## Steps to follow:
1. **Click the link**: `https://d-906625d278.awsapps.com/start`
2. **Sign in**: Use your AWS credentials
3. **Select Account**: Choose the right AWS account
4. **Access Services**: Look for Amazon Q Pro option
5. **Upgrade**: Follow the upgrade prompts

## If Amazon Q Pro is available:
- Click on Amazon Q service
- Look for "Upgrade to Pro" option
- Follow billing setup

## Alternative:
```bash
# Check current Q subscription
aws q describe-subscription

# List available plans

```
