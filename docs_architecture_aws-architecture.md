# ☁️ AWS Architecture Overview

WOOFY McWOOFSON is built on a secure, scalable AWS stack:

- **AWS Lambda:** Serverless compute for AI logic and integrations
- **API Gateway:** Secured entry point for all requests
- **S3:** Secure document storage
- **KMS:** Encryption for data at rest
- **CloudWatch:** Logging, monitoring, and alerting
