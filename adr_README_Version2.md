# 🦴 Architectural Decision Records (ADR) – WOOFY McWOOFSON

This directory contains all key architectural decisions for the project.  
Each ADR documents the context, decision, and consequences for future teams—ensuring zero information loss and full auditability. 🐶

## How to Use

- Create a new ADR for every major design, technology, or process decision.
- Use the provided template (`adr/TEMPLATE.md`).
- Number ADRs sequentially: `0001-initialize-adr-structure.md`, `0002-lambda-handler-refactor.md`, etc.
- Reference ADRs in PRs and `CHANGELOG.md` when relevant.
