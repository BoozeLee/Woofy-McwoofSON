# Branding Assets and Guidelines

Maintained by BoozeLee, 2025-09-08

## Overview

This directory contains all branding assets and guidelines for the Woofy McWoofson project. It includes logos, badge templates, and any custom icons used throughout the project.

## Branding Guidelines

- All branding assets should reflect the playful and friendly nature of the Woofy McWoofson project.
- Use the provided logos and badges consistently across documentation and promotional materials.
- Ensure that all assets are in SVG or PNG format for scalability and quality.

## Assets

- Logos: Include various formats and sizes for different use cases.
- Badges: Use Shields.io for displaying project status (e.g., open source, security compliant).
- Custom Icons: Any additional icons that align with the branding theme.
