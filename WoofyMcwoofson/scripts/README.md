# README for Scripts

This directory contains various scripts that facilitate the development and maintenance of the WoofyMcwoofson project. 

## Available Scripts

- **`run_lint.sh`**: This script runs linting checks on the codebase to ensure code quality and adherence to coding standards.
  
- **`run_tests.sh`**: This script executes the test suite to validate the functionality of the project, ensuring that all features work as intended.

## Usage

To use these scripts, navigate to the `scripts` directory and execute the desired script in your terminal. Ensure that you have the necessary permissions and that your environment is set up correctly.
