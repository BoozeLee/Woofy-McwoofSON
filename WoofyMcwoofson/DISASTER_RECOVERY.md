# Disaster Recovery Plan

Amp Recovery: Backup strategies for atomic resilience.

- GitHub: Repo archiving.
- AWS: S3 snapshots, DynamoDB point-in-time.
- Local: Git bundle daily.

## Recovery
- Restore: `git clone` from backup.
- Test: Quarterly drills.
