# 🐕 Woofy McWoofson Demos

Maintained by BoozeLee, 2025-09-08

This directory contains example scripts and user flows that demonstrate the capabilities of the Woofy McWoofson project. These demos are designed to help users understand how to interact with the API and utilize the automation features effectively.

## Example Demos

- **Automated Onboarding**: A script that showcases the onboarding process using the Woofy API.
- **Health Check**: A simple demonstration of the API's health check endpoint.

## Usage

To run the demo scripts, ensure you have the necessary environment set up and execute the scripts as follows:

```sh
# Example command to run the automated onboarding demo
sh run_automated_onboarding.sh
```

For more detailed instructions on each demo, please refer to the individual script files within this directory.
