## Cloud (Hosted SaaS)
- Best for: Zero infra, fast onboarding.
- Requirements: Org owner, subscription (50K Actions minutes, 50 GB storage, 99.9% uptime).
- Trials: 30-day free.
- Features: Advanced security, SSO, audits.
- Data Residency: EU (Oct 2024+), AU/US.
- Setup: Sign up, upgrade org, configure SSO/audits/domains.

## Server (Self-Hosted)
- Best for: Compliance control.
- Requirements: License (45-day trial), platform (AWS/Azure), admin skills.
- Hardware: Per users (e.g., 8 vCPUs/48 GB for 1,000).
- Setup: Provision VM, deploy OVA/AMI, apply license.

Decision: Cloud for revenue sprints; Server for sovereignty.
