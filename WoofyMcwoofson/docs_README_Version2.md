# 📚 Bakery Street Project Documentation

Maintained by BoozeLee, 2025-09-08

## Structure

- `/architecture/` — Diagrams, flowcharts, and system overviews
- `/api/` — OpenAPI specs and endpoint docs
- `/demos/` — Example scripts, user guides, and demo flows

## Requirements

- Every directory must contain a `README.md` with a summary and maintainer/date header.
- All docs must be emoji-rich, clear, and dog-branded.
- Architecture diagrams (Mermaid, SVG, or PNG) required for all major flows.
- All API endpoints must be documented in OpenAPI format.
- AI transparency and demo scripts must be included in `/demos/`.
