# 🐶 OAuth Client Registration – Step-by-Step

_Last updated: 2025-09-08_

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create or select project
3. APIs & Services > Credentials > Create Credentials > OAuth client ID
4. Choose app type, set URIs/IDs
5. Download and secure credentials
6. Update knowledge vault with details (never public docs)
7. Rotate secrets at least quarterly; log in `CREDENTIAL_ROTATION_AND_HISTORY_CLEANUP.md`
