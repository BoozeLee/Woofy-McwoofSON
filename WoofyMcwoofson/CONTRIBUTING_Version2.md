# 🤝 Contributing to WOOFY McWOOFSON

Thank you for your interest in contributing to the WOOFY McWOOFSON enterprise automation suite!

## 📝 How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Describe your changes** clearly in commits and PRs.
3. **Test your code** — all code must pass lint and security tests.
4. **Do not include secrets, credentials, or sensitive info** in any commit.
5. **Submit a pull request** and follow the PR template.
6. **All contributions are subject to review** by the maintainers and must comply with the LICENSE and IP protection terms.

## 📜 IP and Ownership

- By contributing, you agree your contributions are licensed under the project’s LICENSE.
- You may not submit code you do not have the right to share.
- IP theft, plagiarism, and unauthorized use of third-party code will result in a permanent ban and possible legal action.

## 🛡️ Security

- Report vulnerabilities via [SECURITY.md](SECURITY.md).
- Never share or include secrets in issues or PRs.

## 🐾 Code Style

- Keep to project conventions.
- Emoji and dog references are encouraged in docs and comments!

## 📣 Communication

- Issues and PRs must remain professional and respectful.
- All contributors must follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Thank you for keeping WOOFY secure, professional, and paws-itively awesome!
