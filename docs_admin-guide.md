# 🦴 WOOFY Admin Guide

## 🛡️ Admin Tasks

- Manage users via AWS Cognito or SSO
- Configure API integrations in `/integrations/`
- Monitor logs in AWS CloudWatch
- Schedule audits and compliance scans

## 🐾 Maintenance

- Keep dependencies up to date
- Rotate API keys regularly
- Review security logs weekly

For advanced setup, see `/docs/architecture/`.
