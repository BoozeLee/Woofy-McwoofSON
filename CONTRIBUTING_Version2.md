# 🦴 Contributing to WoofyMcwoofson

Thank you for wanting to fetch some code or docs into WoofyMcwoofson! Here’s how to make your mark:

## How to Contribute

1. **Fork** this repo, then clone your fork.
2. **Create a branch:**  
   `git checkout -b feature/your-cool-trick`
3. **Make your changes** — code, docs, or dog-emoji improvements welcome!
4. **Test everything:**  
   - Run all tests: `pytest` (for Python), `npm test` (for Node), etc.
   - Lint: `flake8 .` or `npm run lint`
5. **Commit with a fun, clear message:**  
   `git commit -m "🐾 Add tail-wagging animation to onboarding screen"`
6. **Push to your fork** and open a **Pull Request**.
7. **Describe your changes** clearly. Add screenshots, diagrams, or memes if you can!
8. **Wait for review:**  
   - Amazon Q will review for security/compliance.
   - The team will check for code quality, clarity, and good dog jokes.

## Guidelines

- Be friendly and helpful—help the next pup learn your trick!
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Document new features in `/docs/` or the Knowledge Vault.
- All critical changes must be reviewed by Amazon Q.
- Keep commits atomic and clear.

Happy coding, and may your fetches always return true! 🐶
